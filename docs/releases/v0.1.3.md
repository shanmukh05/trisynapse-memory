# v0.1.3

This release makes Trace and Recall inspectable in Memory Viewer, lets Python applications register trusted extension packs for new source kinds and retrieval branches, and adds a short starter notebook for the production engine.

## ✨ Highlights

- Studio’s home is Memory Viewer: Trace, BM25, vectors, claims, Episode Recall, and the retrieval graph are catalog-driven tabs rather than a hardcoded page list.
- Python applications can pass trusted extension packs into `MemoryEngine.open(extensions=[...])` to add source handlers, Formation processors, Recall channels, and retrieval branches.
- Playground and API search can run without writing a Query Run (`persist=false`), so inspection does not fill query history.

## 🚀 New Features

- **Extension packs.** Register a `SourceHandler`, `FormationProcessor`, `RecallChannel`, or `RetrievalBranch` through `ExtensionSpec`. Recall records stay in core SQLite storage, must cite active Trace, and rebuild when `storage_revision` changes (`rebuild_extension()`). Weighted RRF remains the default `FusionStrategy`; callers can also replace the post-fusion `CandidateReranker`. CLI and REST do not auto-discover plugins.
- **Memory catalog and inspect APIs.** `GET /api/v1/memory/catalog` lists helpers, retrieval branches, and extension health. Companion routes cover documents, BM25 terms, claims, vector projections/neighbors, and the retrieval graph. Python exposes `memory_catalog()` and the same inspect methods; the TypeScript client adds `getMemoryCatalog()`.
- **Retrieval graph view.** `GET /api/v1/memory-graph?view=retrieval` shows the `followed_by` and `about_same_entity` neighborhood the graph route actually walks, with neighbor expansion for large stores.
- **Non-persistent search.** `MemoryEngine.search(..., persist=false)`, `POST /api/v1/search` with `persist: false`, and `search({ persist: false })` in the TypeScript client skip writing a Query Run. Default remains `true`.
- **Custom source kinds.** `SourceInput.kind` is an open string, so an extension can introduce a new kind without a closed enum. The TypeScript `SourceKind` type accepts the same.
- **Starter notebook.** `notebooks/starter.ipynb` ingests `data/sample/`, lists Trace and Recall, and runs search and query against a local store.

## 🔧 Improvements

- Studio playground search uses production retrieval with `persist=false`, then “Open as Query” is the only path that writes history.
- Unknown Recall helpers still render from generic `items[]` using the declared visual family (`timeline`, `table`, `postings`, `embedding`, `cards`, `graph`).
- Existing `QueryPlanner` and `RouteRegistry` APIs remain for ranking the built-in candidate index; new end-to-end channels should use extension packs.

## 📦 Other Changes

- Studio graph views no longer depend on Cytoscape.
- Research benchmark notebooks under `notebooks/` are replaced by the starter notebook. Packaged benchmark adapters remain in the Python library.
