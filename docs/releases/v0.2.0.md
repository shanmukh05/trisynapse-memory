# v0.2.0

This release refactors the engine architecture around a durable Memory Log and rebuildable Indexes, adds complete algorithmic specifications, transitions from deltas to memory records, replaces Episode Recall with Group Summaries, and unifies ingestion and indexing pipelines.

## ✨ Highlights

- **Memory Log and Indexes architecture**: Clear separation between the durable, sequential **Memory Log** (`engine/memory_log`), **Ingest** pipeline (`engine/ingest`), and rebuildable **Indexes** (`engine/indexes`).
- **Comprehensive Algorithm Specifications**: New `docs/algorithms.md` details the exact mathematical formulas for BM25, cosine vector similarity, weighted Reciprocal Rank Fusion (RRF), margin-based confidence scoring, and citation grounding.
- **Group Summaries & Facts**: Prompts and records transition to evidence-grounded facts (`facts.md`, `image_facts.md`) and scoped group summaries (`group_summary.md`) with explicit `group_id` routing.
- **Unified Multi-Item Ingestion**: Python `add_raw_source()`, `add_many()`, and REST endpoints `/api/v1/memory/raw-sources` and `/api/v1/memories/many` streamline raw source and batch writes.

## 🚀 New Features

- **Formal Algorithms Documentation (`docs/algorithms.md`)**: Complete mathematical definitions, state transitions, retrieval fusion algorithms, context budget packing, and grounding invariants.
- **Group Summaries**: Group summary index and APIs (`GET /api/v1/groups`, `GET /api/v1/groups/{group_id}`) replace episode recall across SQLite tables, background jobs, Studio inspection, and routing seeds.
- **Raw-Source & Multi-Item APIs**: Added `add_raw_source()` and `add_many()` on `MemoryEngine`, `/api/v1/memory/raw-sources` and `/api/v1/memories/many` in REST, and updated `add()` / `addBatch()` in the TypeScript client.
- **Embedding Index Inspection**: Renamed vector helper to "Embedding index" across Studio and catalog APIs (`/api/v1/memory/vectors/projection`), reflecting rebuildable secondary index semantics.

## 🔧 Improvements

- **Studio Memory Viewer**: Tabs updated to "Memory log", "Documents", "BM25", "Embedding index", "Group summaries", "Claims", and "Graph". Filtering now supports `group id` and `source id`.
- **Benchmark Adapters**: Updated LoCoMo, LongMemEval, HaluMem, and MemoryDoc benchmark adapters to the memory log, group summary, and fact models.
- **Studio E2E & Browser Tests**: Playwright accessibility and interaction tests updated and verified across desktop and mobile/narrow viewports.
- **Clean Wheel & Distribution Bundles**: Wheel and source distributions verified to include hashed Studio production assets, canonical logos, and updated versioned prompt templates.

## ⚠️ Breaking Changes

- **Engine Package Structure**:
  - `engine/trace/` moved to `engine/memory_log/`
  - `engine/formation/` moved to `engine/ingest/`
  - `engine/recall/` moved to `engine/indexes/`
- **Terminology & Schema**:
  - `MemoryDelta` and delta-based terminology transitioned to `MemoryRecord` in the memory log.
  - `batch_id` renamed to `group_id` across models, query filters, REST parameters, and the TypeScript SDK.
  - `episode_recall` replaced with `group_summary` in prompts and catalog routes.
- **REST API**:
  - `/api/v1/batches` replaced by `/api/v1/groups`.
  - Batch memory creation route updated to `/api/v1/memories/many`.

## 📦 Other Changes

- Python dependencies locked in `uv.lock`, package metadata bumped to `0.2.0` across `pyproject.toml`, `packages/js-sdk/package.json`, `packages/studio/package.json`, and installers (`install.sh`, `install.ps1`).
