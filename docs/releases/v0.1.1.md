# v0.1.1

Patch release that republishes installers at 0.1.1 and simplifies the tagged release pipeline.

## 🔧 Improvements

- Installers now pin `trisynapse-memory[all]==0.1.1` on macOS, Linux, and Windows.
- Tagged releases always build and publish the current tree instead of trying to reuse an existing PyPI artifact.

## 📦 Other Changes

- Removed the one-off PyPI artifact download helper used only by the previous release workflow.

**Full Changelog:** https://github.com/shanmukh05/trisynapse-memory/compare/v0.1.0...v0.1.1
