# Trisynapse Memory 0.3.0

Trisynapse Memory adds the OmniMemEval benchmark workflow and expands the controls for retrieval, evidence readout, and source navigation.

- **Memory.** The default readout returns stored observations and extracted facts with source links. When you retract an observation, search also excludes facts that depend on it. Use the raw-source readout when the reader should receive only original observations.
- **Benchmarks.** Run LoCoMo, PersonaMem-v2, HaluMem, BEAM-100K or BEAM-10M, and LongMemEval through the pinned OmniMemEval harness. Named runs save their settings, stage progress, per-question outputs, and reports. Use `--resume` to continue an unfinished run. Benchmark execution requires macOS, Linux, or WSL.
- **Terminal and SDK.** The terminal preserves backslashes in Windows paths. The TypeScript client exposes the new retrieval settings and continues to call the Python service.
- **Distribution.** The Python wheel includes the terminal and Studio. The Docker image also builds Studio from source. Release CI checks the installed wheel and npm tarball together before publishing either package.

## Upgrade

Make a backup of an existing store and run `trisynapse-memory validate` after upgrading.

```sh
pip install --upgrade 'trisynapse-memory[all]==0.3.0'
npm install @trisynapse/trisynapse-memory@0.3.0
```

If you installed through a GitHub release script, run the latest installer again. See [Operations](../operations.md) for backup and configuration and [Benchmarks](../benchmarks.md) for evaluation protocols.
